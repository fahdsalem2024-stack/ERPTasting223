# ERP Test Automation

منصة شاملة لأتمتة اختبارات نظام ERP بـ Python + Selenium + Flask

## المميزات

- اختبارات أتمتة (Selenium + Pytest)
- موقع ويب متكامل (Flask + Bootstrap 5)
- دعم عربي/إنجليزي
- Dashboard + Charts
- تصدير PDF/Excel/CSV/JSON
- إدارة مستخدمين
- Slack Notifications
- Docker + CI/CD

## التشغيل السريع

### Docker
docker-compose up -d
### محلي
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python web/app.py
